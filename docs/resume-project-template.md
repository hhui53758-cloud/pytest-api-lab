## 基于 Pytest 的接口自动化测试框架｜个人实践项目

**项目时间：**[实际起止年月]

**技术栈：**Python、Pytest、Requests、FastAPI、SQLite、logging、pytest-html、Git

**项目简介：**以本地任务管理 API 为测试对象，围绕登录、任务增删改查与用户权限，搭建接口自动化测试框架，实现测试准备与清理、参数化执行、数据库核对、日志记录和报告输出。

- **测试设计：**依据接口约定和业务规则，运用等价类、边界值和状态验证设计正常、异常及权限用例，覆盖标题长度、非法状态、资源不存在、任务更新与跨用户访问等场景。
- **框架开发：**基于 Pytest 与 Requests 封装公共请求模块，统一管理地址、认证信息与超时配置；使用 Fixture 完成登录、数据准备及 yield 清理，支持用例独立执行与重复运行。
- **参数化与数据验证：**采用参数化复用边界及异常测试逻辑，通过标记组织冒烟与回归用例；结合状态码、响应字段和 SQLite 查询，核对任务创建、更新、删除后的数据一致性。
- **异常定位与报告：**记录请求响应、执行耗时及失败上下文，对认证信息脱敏，使用 pytest-html 输出报告；结合日志与数据库完成缺陷复现和修复回归练习。
- **项目交付：**完成20个执行场景，整理源代码、用例清单、运行说明和测试报告，形成可复现的个人自动化测试项目。
