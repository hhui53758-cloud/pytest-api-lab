# 第五章：数据库、权限与问题定位

阅读 framework/database.py 和 test_other_user_cannot_access_task。

状态码验证请求行为；字段验证业务结果；SQL 查询核对持久化与副作用。DatabaseProbe 只做 SELECT，准备和清理通过 API 完成。

权限测试先由 Alice 创建资源，再由 Bob 查询、修改、删除。预期403，同时检查原记录不变，Alice仍可访问。这比只检查403更完整。

教学缺陷练习：
1. 本地记录当前Git状态，定位 app/api.py 的 owned_task。
2. 临时移除其所有权拒绝分支，保持其余行为不变。
3. 执行跨用户权限用例，观察本应403的请求变成200或204，以及失败信息。
4. 恢复检查，重复执行该组用例与全量回归。
5. 保存复现条件、预期/实际、相关证据和回归结果。

练习是主动构造的教学缺陷，不等同于真实线上缺陷。不要将移除权限检查的版本发布到GitHub。

独立练习：说明接口返回正确标题，但SQL记录仍是旧标题时应如何继续排查。
