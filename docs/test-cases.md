# 20 个执行场景

参数化展开后共 20 个场景，11 个测试函数。用例数量可用 python -m pytest --collect-only -q 验证。

| 编号 | 场景 | 主要验证 |
| --- | --- | --- |
| TC01 | 正确账号登录 | 200、令牌格式、令牌可授权 |
| TC02 | 密码错误 | 401、错误类别 |
| TC03 | 用户不存在 | 401、错误类别 |
| TC04 | 健康检查 | 200、JSON、服务状态 |
| TC05 | 创建并查询 | 201/200、默认状态、返回与数据库一致 |
| TC06 | 更新任务 | 200、标题状态变化、查询与数据库一致 |
| TC07 | 删除任务 | 204空正文、后续404、数据库记录消失 |
| TC08 | 标题长度0 | 422、标题字段错误、数据库无新增 |
| TC09 | 标题长度1 | 201、最小边界、数据库一致 |
| TC10 | 标题长度50 | 201、最大边界、数据库一致 |
| TC11 | 标题长度51 | 422、超界、数据库无新增 |
| TC12 | pending状态 | 201、状态与数据库一致 |
| TC13 | running状态 | 201、状态与数据库一致 |
| TC14 | done状态 | 201、状态与数据库一致 |
| TC15 | 非法状态 | 422、状态字段错误、无新增 |
| TC16 | 资源不存在 | 404、错误类别 |
| TC17 | 未登录创建 | 401、认证提示、无新增 |
| TC18 | 跨用户查询 | 403、记录保持、所有者仍可访问 |
| TC19 | 跨用户修改 | 403、记录未变化 |
| TC20 | 跨用户删除 | 403、记录未删除 |

冒烟为 TC01、TC04、TC05、TC07，完整回归为全部场景。各用例通过 task_factory 清理自己创建的数据；异常写入通过 SQL 记录数检查副作用。

范围：本地 API 功能与基础权限验证；未声称覆盖所有安全风险、所有字段组合或并发性能。
