# Pytest 接口自动化测试项目：教学目录

## 项目目标

以本地任务管理 API 为对象，使用 Python、Pytest、Requests 和 SQLite 完成接口自动化实践。最终能够独立新增用例、解释框架结构、定位失败并输出测试报告。

被测后端由导师提供并逐章扩展，学习重点是测试设计、框架代码与问题定位。

## 180 分钟参考安排

时间按环境顺利、具备 Python 和测试基础估算。遇到问题时先保证核心功能与理解，实际完成内容以验收为准。

| 章节 | 时间 | 核心内容 | 验收产物 |
| --- | --- | --- | --- |
| 第一章：环境、HTTP 与第一条测试 | 15 分钟 | 虚拟环境、服务启动、请求响应、JSON、断言、测试发现 | /health 测试通过，能解释失败输出 |
| 第二章：任务接口与测试设计 | 30 分钟 | POST/GET/DELETE、资源 ID、正常/异常/边界场景、手动清理 | 创建查询、删除、非法输入、404 等用例 |
| 第三章：Fixture 与登录状态 | 30 分钟 | conftest.py、Fixture 注入、scope、yield、测试账号与登录、数据清理 | 独立且可重复执行的用例 |

## 详细教学目录

### 第一章：环境、HTTP 与第一条测试

1. Python 解释器、虚拟环境与依赖。
2. 服务端、客户端和测试框架的职责。
3. URL、HTTP 方法、状态码、响应头、正文。
4. JSON 字符串与 Python 字典。
5. assert 与 Arrange / Act / Assert。
6. Pytest 测试发现、执行命令与失败输出。

### 第二章：任务接口与测试设计

1. 接口约定与业务规则。
2. POST 请求体与 json 参数。
3. 动态资源 ID 与接口链路。
4. 201、204、404、422。
5. 等价类、边界值与状态验证。
6. try/finally 与测试数据清理。

### 第三章：Fixture 与登录状态

1. 测试前置条件、执行和后置清理。
2. @pytest.fixture 与参数注入。
3. conftest.py 的作用。
4. scope 的生命周期与共享状态风险。
5. yield 前后的准备与清理。
6. 测试账号、登录凭据与授权请求。
7. 用例独立性及重复执行。

### 第四章：参数化与框架组织

1. 用例数据与测试逻辑。
2. @pytest.mark.parametrize、ids。
3. smoke/regression 标记及选择执行。
4. Requests Session 与公共请求封装。
5. base_url、timeout 与配置。
6. 连接异常、请求超时和断言失败的区别。
7. 维护清楚的模块边界，避免过度封装。

### 第五章：SQLite、权限与缺陷定位

1. SQLite、表、记录与基础 SQL。
2. 通过 SQL 核对创建、更新和删除结果。
3. 测试数据隔离与独立测试数据库。
4. 两个用户的资源访问边界。
5. 请求、响应、日志与数据证据。
6. 复现一个教学预置缺陷，明确记录其教学性质。
7. 修复后的关联回归验证。

### 第六章：日志与报告

1. logging 日志级别与格式。
2. 用例、请求响应、耗时与失败信息关联。
3. 密码和认证凭据脱敏。
4. pytest-html 报告生成与阅读。
5. 通过、失败、错误、跳过的区别。
6. 已覆盖、未覆盖与遗留问题总结。

### 第七章：独立验收与项目交付

1. 独立新增一条完整用例。
2. 用例单独、整套和重复执行。
3. README：安装、启动、执行、报告。
4. Git 保存阶段成果。
5. 解释结构、设计选择与排查案例。
6. 根据实际成果编写简历。
