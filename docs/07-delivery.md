# 第七章：独立验收

源码已提供不代表已经掌握。按以下步骤完成个人验收：

1. 从接口约定中独立选择新场景，写出输入、预期及断言。
2. 单独执行、整套执行、重复执行均通过。
3. 临时改错一个预期，读懂实际/预期差异后恢复。
4. 完成第五章权限缺陷练习并恢复正确代码。
5. 使用锁定依赖在新环境运行项目。
6. 解释Fixture作用域、数据清理、参数化、认证和SQL核对。
7. 对照真实完成内容修改简历与项目时间。

交付材料：代码、用例清单、README、报告、脱敏日志、教学缺陷练习记录。

完成后可描述“个人接口自动化测试实践”，20条按参数化展开后的数量计。新增场景后更新文档和数字。能够解释设计与排查过程后，再把相关能力写入技能栏。
